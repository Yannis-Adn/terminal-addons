# pinned-prompt

Your last message pinned in a framed band above the Claude Code prompt, so you never scroll up to remember what you asked. Click `📌 You ▸` to unfold your last five messages, the latest in full. Labels follow Claude Code's `language` setting (English or French).

```
/plugin marketplace add Yannis-Adn/terminal-addons
/plugin install pinned-prompt@terminal-addons
```

Full documentation: see the [repository README](../../README.md#pinned-prompt) ([français](../../README.fr.md#pinned-prompt)).
